البناء في GitHub عبر `.github/workflows/webos.yml` عند رفع فرع `codex/**` أو `main`: تثبيت أدوات التطوير، فحص الصياغة والمنطق، فحص واجهة Chromium بمحاكاة الفيديو دون جلب أي بث، ثم تغليف IPK. هذا لا ينشر تطبيقًا أو إصدارًا للمستخدمين.

```sh
git push -u origin <work-branch>
gh run watch <run-id> --exit-status
gh run download <run-id> --dir artifacts/github
```

الفحص الخفيف عند الحاجة: `npm run check` و`npm run check:ui`. أداة Playwright تخص التطوير والفحص فقط ولا تدخل حزمة التلفزيون. فحص الواجهة يحاكي أحداث الفيديو ويمنع كل اتصالات الوسائط والخارج؛ لا يثبت توافق webOS أو جودة تشغيله.

`npm run preview` يشغّل معاينة واجهة فقط على `127.0.0.1:4173`. لا يتصل بمصدر بث دون إدخال واختيار صريحين. لا تنشره على الإنترنت. أداة LG تحتوي اعتماديات بناء قديمة؛ لا تُضمّن في تطبيق التلفزيون ولا تُحدّث عشوائيًا.

## طريقة إدخال الرابط المجربة

1. افتح فحص التطبيق من ويندوز: `ares-inspect.cmd --device lg-tv --app com.amjadoh.lgstream --open`.
2. في Console، إذا منع Chrome اللصق، اكتب يدويًا `allow pasting` ثم Enter. لا تطلب من أمجد إعادة محاولات الحافظة أو قراءة `navigator.clipboard`؛ ثبت أنها تعطي `NotAllowedError`.
3. الصق `document.getElementById('playlist-url').value=prompt('الصق رابط M3U')||''` ثم Enter. هذه هي الطريقة المجربة التي تفتح خانة إدخال فعلية في LG ThinQ وتضع نتيجتها في حقل القائمة؛ لا تستبدلها بمجرد `focus()` ولا بمحاولة `navigator.clipboard`.
4. الصق رابط الاشتراك داخل نافذة LG ThinQ محليًا فقط، ثم اضغط زر تحميل القائمة من التلفزيون. لا تطلب الرابط أو بياناته في المحادثة ولا تضع الرابط نفسه داخل أمر Console أو سجل الأوامر.

- أُضيف بطلب أمجد للمقارنة من التلفزيون نفسه. الاختبار لا يحدد نوع الاتصال آليًا ولا يغيّر إعدادات الشبكة، ولا يرفع الحد المادي لمنفذ LAN. لا نفترض سبب قراءة أقل من 100Mbps قبل نتيجة الجهاز.
- المصدر: [Cloudflare Speedtest](https://github.com/cloudflare/speedtest)، المسار `https://speed.cloudflare.com/__down` ومعامل `bytes`. التطبيق يستخدم طلب قياس واحدًا فقط بلا مكتبة Cloudflare أو رفع ملفات أو إرسال نتائج.
- `fetch` مع `cache: no-store` ومعامل متغير، `credentials: omit` و`referrerPolicy: no-referrer` ورفض إعادة التوجيه. CSP تسمح بالاتصال بمسار القياس هذا فقط؛ روابط البث لا تدخل الطلب أبدًا.
- الحساب: مجموع بايتات التنزيل × 8 ÷ المدة بالثواني ÷ مليون. المدة تبدأ قبل طلب HTTP وتشمل الوصول للترويسات وأي توقف حتى نهاية الطلب أو المهلة. لذلك هو متوسط نقل حمولة بطلب واحد، وليس ضمان بلوغ سرعة الاشتراك القصوى.
- استجابة HTTP = الزمن من بدء الطلب إلى وصول ترويسات الرد، ويشمل زمن إنشاء الاتصال عند الحاجة؛ ليست ping ولا قياس فقد حزم. عند انتهاء 8 ثوانٍ بعد استقبال جزء من البيانات تعرض نتيجة جزئية محسوبة على كامل المدة؛ الإلغاء اليدوي لا يحفظ نتيجة.
- تحقق خادم صغير فقط بتاريخ 2026-11-14: استجابة HTTP 200 بحجم 1024 بايت مع `Access-Control-Allow-Origin: *` و`Cache-Control: no-store, no-transform` وOrigin فارغ (`null`). وطلب 1024 بايت آخر نجح عبر Chromium من ملف محلي مع CSP الفعلية (`type: cors`). طلب Python أول بلا هوية متصفح رُفض 403؛ الطلبات بهوية المتصفح نجحت. هذا تحقق من المسار وليس تجربة سرعة التلفزيون.
- التوافق مع TLS وCORS ومحرك webOS والسرعة على التلفزيون ينتظر تجربة المستخدم. لا توجد قياسات فعلية للكيبل/الواي فاي، ولا أي اختبار بث أو تأكيد Dolby.
- يرى مزود القياس عنوان الاتصال كأي خدمة إنترنت؛ التطبيق لا يرسل تاريخ النتائج أو بيانات الاشتراك. النتائج تزول بانتهاء جلسة التطبيق.

## الخطوة الجاية

- الجاي باختصار: تثبيت المرشح واختبار الحفظ والتنقل على التلفزيون
- 0.7.0 تستعيد القائمة بلا طلب شبكة عند فتح التطبيق، وتحفظ القسم والمجموعة والترتيب والبطاقة/التفاصيل المحددة دون حفظ الرابط في localStorage. قد يحذف النظام البيانات عند إزالة التطبيق أو تحديث الحزمة؛ يلزم التحقق فعليًا بعد إغلاق التطبيق وإعادة تشغيل التلفزيون.
- يظهر في الإعدادات زر «تحديث القائمة» ويستخدم الرابط المحفوظ دون عرضه أو إعادة إدخاله. بعد 24 ساعة من آخر حفظ ناجح يفحص التطبيق التحديث عند الفتح أو العودة وأثناء بقائه مفتوحًا؛ التطبيق المغلق لا يعمل في الخلفية. أي مشاهدة أو محاولة تشغيل أو تبديل مؤجل تؤجل التحديث حتى يتوقف البث وتعود واجهة التصفح. الفشل لا يغير وقت آخر نجاح ولا القائمة السابقة؛ يعاد تلقائيًا بعد ساعة، والإلغاء لمصلحة تشغيل/اختبار يعاد بعد خمس دقائق، دون حلقة متصلة.
- بطاقات الأفلام والمسلسلات تستخدم نافذة خفيفة وتمريرًا مستمرًا بالريموت بلا أزرار صفحات، وصور العناصر الظاهرة فقط. خيارات الترتيب تعتمد فقط على حقول M3U المتاحة؛ الحقول الناقصة تأتي أخيرًا ولا توجد طلبات تفاصيل جماعية.
- زر الإعلان يشغّل رابط المزود إن توفر؛ وإلا يفتح متصفح LG على بحث YouTube باسم العمل والسنة فقط. العودة لنفس التفاصيل مدعومة منطقيًا وتنتظر تحقق التلفزيون من إطلاق المتصفح والعودة.
- تحتفظ خوادم المشروع بآخر مخرجي بناء ناجحين فقط. لا تُحفظ نسخة مشروع أو IPK دائمة على لابتوب العمل؛ ملف التثبيت المؤقت يحذف بعد نجاح التثبيت.
- قاعدة قرار نهائية من أمجد: ثبات التشغيل أهم من أي ميزة؛ احذف أو أجّل ما يؤثر على التقطيع أو سرعة البدء أو ذاكرة المشاهدة.
- تفضيل واجهة مؤكد من أمجد: قائمة القنوات والمجموعات في اليسار، والفيديو في اليمين، وتختفي القائمة عند ملء الشاشة.
- عند تشغيل القناة تظهر شارة جودة فعلية مختصرة فقط: `SD` أو `HD` أو `FHD` أو `QHD` أو `4K`. تعتمد على أبعاد الفيديو المفكوكة وتتحدث عند تغيرها، لا على تسمية المزود.
- نُفذت في 0.3.0 قائمة يسارية فعلية مع اختيار المجموعة والبحث والمفضلة للجلسة وشارة الجودة. كلها تعمل داخل الذاكرة، ولا تضيف طلبات شبكة أو عنصر وسائط أو إعادة فتح للمصدر أثناء التشغيل.
- تستبدل 0.4.0 القائمة المنسدلة بعمود مجموعات أقصى اليسار وقائمة قنوات بجانبه، وتعرض مجموعات الأفلام كبطاقات CSS بلا صور شبكة. ضغط OK مرتين على القناة الحالية يدخل ملء الشاشة دون إعادة المصدر. خيار حجم الصورة يبدل بين ملائم وملء وتمديد على عنصر الفيديو نفسه.
- تضيف 0.5.0 قائمة رئيسية مخفية تظهر بسهم اليسار وتختفي بعد اختيار بث أو أفلام أو مسلسلات أو مفضلة، وبحثًا شاملًا يقسم النتائج حسب النوع. أسماء المجموعات عريضة وتلتف لسطرين. إذا احتوت M3U على `url-tvg` و`tvg-id` يُحمّل أول 4MB من EPG بعد ثانيتين من الخمول فقط، ويُلغى فور بدء أي بث؛ اسم البرنامج الحالي يظهر تحت القناة عند توفره.
- تعتمد 0.5.2 تصنيف المحتوى على مسار الرابط فقط: `/movie/` للأفلام و`/series/` للمسلسلات، وما عداه يبقى بثًا مباشرًا. لا يستخدم اسم المجموعة كحل احتياطي حتى لا يختلط المحتوى مع القنوات.
- في قسمي الأفلام والمسلسلات تخفي 0.5.1 عمود القنوات المكرر، وتعرض عمود المجموعات مع بطاقات المحتوى في المساحة اليمنى. قسم البث وحده يحتفظ بعمودي المجموعات والقنوات.
- استُلهم ترتيب الميزات من صفحة TiviMate الرسمية دون نسخ كود أو علامة: المجموعات والبحث والمفضلة أولًا، ثم EPG وCatch-up، ثم VOD والاستئناف. التسجيل مؤجل. Multiview رغبة لاحقة بحد شاشتين فقط، معطل افتراضيًا، ولا يُنفذ قبل قبول المشغل الواحد ويُلغى إذا أثر على الثبات.
- الرقابة الأبوية مستبعدة صراحة بطلب أمجد؛ لا تضف PIN أو قفل قنوات أو إعداداتها.
