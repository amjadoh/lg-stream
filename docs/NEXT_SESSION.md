## استئناف العمل

- المثبت على التلفزيون0.7.4 بعد دمج#4 ونجاح فحوص main. أكد أمجد فتحه وظهور قائمته. التثبيت من Windows PowerShell عبر الأدوات المقترنة سابقًا؛ لا وصول تنفيذ مباشر لكمبيوتره من السيرفر.
- تجربة الجهاز كشفت تعليق select الصوت في فيلم بمسار واحد وفي البث، وعدم الوصول للترجمة. Home يعيد التطبيق المعلق؛ إغلاقه بالكامل باستخدام ares-launch.cmd --device lg-tv --close com.amjadoh.lgstream ثم فتحه لا يحذف القائمة.
- مرشح0.7.5 يستبدل القائمتين بأزرار داخل التطبيق لجميع الأنواع، مع رجوع واضح وصوت واحد بلا نافذة وحماية تغيّر المسارات والخلفية. صُغرت لوحة التحكم بطلب المستخدم. المنطق المحلي ناجح؛ فحوص GitHub ومراجعة Claude قيد التنفيذ.
- موافقة أمجد السابقة تشمل إرسال الكود المنقح لكلود والدمج بعد نجاح الفحص؛ لا تعِد طلب الموافقة نفسها. لا إصدار/نشر متجر دون إذن منفصل.
- لا مشغل ثانٍ أو proxy أو تحويل أو Luna خاص للوسائط. أولويتنا ثبات المشغل وسرعة التنقل ثم الصورة والصوت.

## الخطوة الجاية

- الجاي باختصار: إصلاح تعليق الصوت والترجمة وتجربته بالتلفزيون
- أكمل المراجعة والاختبارات وحمّل الحزمة الناجحة من GitHub ثم أعط أمجد أمر تحديث PowerShell مع البصمة. يحتفظ التحديث بهوية التطبيق والقائمة، دون إزالة التطبيق.
- على التلفزيون أعد الجزء المتأثر فقط: فتح الصوت والترجمة والتنقل بينهما والرجوع، مع فيلم/حلقة وقناة ضمن جلسة قصيرة. المحاكاة لا تثبت سلوك قائمة LG ولا تشغيل الوسائط.
- قائمة المزود محلية على التلفزيون؛ HDR/HLG غير مثبتين ولم نحدد فيلمًا مؤكدًا. لا تطلب بيانات اشتراك أو روابط في المحادثة.
- احتفظ بآخر مخرجَي بناء ناجحين فقط داخل artifacts، ولا تمس الملفات الشخصية أو Git أو كمبيوتر Windows.
