# ابدأ هنا — الجلسة التالية

1. اقرأ [AGENTS.md](../AGENTS.md) ثم [HANDOFF.md](HANDOFF.md). كل ما في `archive/` تاريخي.
2. المثبت على التلفزيون **0.8.12**، وهو مدموج في main ومنشور بوصفه v0.8.12 (Latest). الخطوة المطروحة: تخصيص القنوات والمجموعات (إخفاء ونقل وإعادة تسمية وتحديد متعدد). التصميم قيد النقاش مع المالك، فلا تبدأ التنفيذ قبل اعتماده.
3. ابدأ بملاحظات المالك من المشاهدة الفعلية على 0.8.12. اطلب منه، عند أي انقطاع، فتح الإعدادات ← «قياسات الجلسة» وقراءة سجل الانقطاعات، أو اقرأه عبر Inspector.
4. المرشح التالي إذا ظهرت حاجة مقاسة: تقليل حجب الواجهة نحو 20ث أثناء تحديث القائمة.
5. لا تكرر اختبارات A→B→A على المزود دون حاجة. كل محاولة تستهلك اتصالًا لدى المزود.
