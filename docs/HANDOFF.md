# تسليم LG Stream — المرحلة صفر

آخر تحديث: 2026-11-14. هذا الملف يصف مشروعًا أوليًا، لا إصدار مشاهدة يومية معتمدًا.

## ما أُنجز

- مستودع خاص: https://github.com/amjadoh/lg-stream
- نسخة العمل على السيرفر: `/home/amjed/projects/lg-stream`.
- تطبيق webOS 0.1.0، معرّفه `com.amjadoh.lgstream`، بلا مكتبات تشغيل خارجية أو خدمات في مسار المشاهدة.
- ثلاثة روابط مباشرة في الذاكرة فقط. القائمة الكاملة M3U وربط Xtream وEPG والأفلام المفهرسة ليست منفذة بعد.
- فصل التحديد عن التشغيل، مشغّل واحد، تجاهل أحداث المصدر القديم، مهلة بدء محدودة، تحرير البث عند الخلفية، وتشخيص بلا روابط.
- برومبت عربي مفصل ومراجعة فعلية من Claude مع قرارات قبول/تعديل موثقة.
- أداة تغليف LG مثبتة محليًا داخل المشروع على السيرفر: `@webos-tools/cli@3.2.6`. Node على السيرفر وقت الإعداد: 20.19.2.

## التحقق وحدوده

- نجح فحص صياغة JavaScript وأربعة اختبارات منطق مركّزة تشمل آخر طلب، تحرير المصدر، الأحداث القديمة، عدم تسريب الروابط، والقياس/مهلة البدء.
- نجح بناء IPK على السيرفر. لا تعتبر نجاح التغليف دليلًا على عمل الفيديو أو الصيغ على التلفزيون.
- لم يُثبَّت التطبيق على التلفزيون بعد. لم يُشغّل أي بث خاص أو عام، ولم يثبت Atmos أو Dolby Vision أو تفوق السرعة على TiviMate.
- مدة الانتظار في لوحة القياس تخص فترات أحداث waiting المكتملة فقط؛ لا تقيس كل توقف محتمل. قياسات playing/currentTime/rVFC تقديرات لا وقت أول صورة مؤكدة.
- ساوندبار عبر HDMI eARC مؤكد من المستخدم، وموديله وإصدار webOS الحالي ما زالا مطلوبين قبل قبول اختبار Dolby.

## البناء والمعاينة

من مجلد المشروع:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run check
npm run package:webos
```

الحزمة: `dist/com.amjadoh.lgstream_0.1.0_all.ipk`. أداة LG تحتوي اعتماديات بناء قديمة يعلن npm إهمال بعضها؛ لا تُضمَّن هذه الاعتماديات في تطبيق التلفزيون. لا تحدّثها عشوائيًا ولا تفرض إصلاحات تكسر أداة LG.

`npm run preview` يشغّل معاينة واجهة فقط على `127.0.0.1:4173`. لا يتصل بمصدر بث دون إدخال واختيار صريحين. لا تنشره على الإنترنت؛ معاينة الكمبيوتر لا تثبت فك صيغ التلفزيون.

## الخطوة التالية على التلفزيون

1. من متجر التلفزيون افتح Developer Mode وسجّل دخول حساب LG Developer بنفسك. فعّل Dev Mode Status، وأكمل إعادة التشغيل ثم Key Server. راجع الوقت المتبقي وجدد الجلسة؛ انتهاء الوضع قد يحذف التطبيق.
2. استخدم كمبيوترًا على نفس شبكة التلفزيون لتسجيل الجهاز بأداة LG واستلام مفتاحه وتثبيت الحزمة. لا تحفظ passphrase أو مفتاح التلفزيون في git ولا ترسله في المحادثة. السيرفر البعيد للبناء؛ لا تفتح منافذ التلفزيون للإنترنت.
3. افتح التطبيق وأدخل مصدرين مباشرين متوافقين محليًا، ثم نفّذ جلسة قصيرة واحدة كما في البرومبت. لا حاجة الآن لقائمة قنوات كاملة.
4. بعد نجاح الأساس فقط، نتحقق من موديل الساوندبار ونجرب عينة Dolby واحدة مناسبة. لا نعد TrueHD Atmos أو DTS لهذا الموديل.

الدليل: https://webostv.developer.lge.com/develop/getting-started/developer-mode-app
