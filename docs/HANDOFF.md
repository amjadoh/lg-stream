## اختبار الاتصال وحدوده

- أُضيف بطلب أمجد للمقارنة من التلفزيون نفسه. الاختبار لا يحدد نوع الاتصال آليًا ولا يغيّر إعدادات الشبكة، ولا يرفع الحد المادي لمنفذ LAN. لا نفترض سبب قراءة أقل من 100Mbps قبل نتيجة الجهاز.
- المصدر: [Cloudflare Speedtest](https://github.com/cloudflare/speedtest)، المسار `https://speed.cloudflare.com/__down` ومعامل `bytes`. التطبيق يستخدم طلب قياس واحدًا فقط بلا مكتبة Cloudflare أو رفع ملفات أو إرسال نتائج.
- `fetch` مع `cache: no-store` ومعامل متغير، `credentials: omit` و`referrerPolicy: no-referrer` ورفض إعادة التوجيه. CSP تسمح بالاتصال بمسار القياس هذا فقط؛ روابط البث لا تدخل الطلب أبدًا.
- الحساب: مجموع بايتات التنزيل × 8 ÷ المدة بالثواني ÷ مليون. المدة تبدأ قبل طلب HTTP وتشمل الوصول للترويسات وأي توقف حتى نهاية الطلب أو المهلة. لذلك هو متوسط نقل حمولة بطلب واحد، وليس ضمان بلوغ سرعة الاشتراك القصوى.
- استجابة HTTP = الزمن من بدء الطلب إلى وصول ترويسات الرد، ويشمل زمن إنشاء الاتصال عند الحاجة؛ ليست ping ولا قياس فقد حزم. عند انتهاء 8 ثوانٍ بعد استقبال جزء من البيانات تعرض نتيجة جزئية محسوبة على كامل المدة؛ الإلغاء اليدوي لا يحفظ نتيجة.
- تحقق خادم صغير فقط بتاريخ 2026-11-14: استجابة HTTP 200 بحجم 1024 بايت مع `Access-Control-Allow-Origin: *` و`Cache-Control: no-store, no-transform` وOrigin فارغ (`null`). وطلب 1024 بايت آخر نجح عبر Chromium من ملف محلي مع CSP الفعلية (`type: cors`). طلب Python أول بلا هوية متصفح رُفض 403؛ الطلبات بهوية المتصفح نجحت. هذا تحقق من المسار وليس تجربة سرعة التلفزيون.
- التوافق مع TLS وCORS ومحرك webOS والسرعة على التلفزيون ينتظر تجربة المستخدم. لا توجد قياسات فعلية للكيبل/الواي فاي، ولا أي اختبار بث أو تأكيد Dolby.
- يرى مزود القياس عنوان الاتصال كأي خدمة إنترنت؛ التطبيق لا يرسل تاريخ النتائج أو بيانات الاشتراك. النتائج تزول بانتهاء جلسة التطبيق.

## الخطوة التالية على التلفزيون

1. من متجر التلفزيون افتح Developer Mode وسجّل دخول حساب LG Developer بنفسك. فعّل Dev Mode Status، وأكمل إعادة التشغيل ثم Key Server. راجع الوقت المتبقي وجدد الجلسة؛ انتهاء الوضع قد يحذف التطبيق.
2. استخدم كمبيوترًا على نفس شبكة التلفزيون لتسجيل الجهاز بأداة LG واستلام مفتاحه وتثبيت الحزمة. لا تحفظ passphrase أو مفتاح التلفزيون في git ولا ترسله في المحادثة. السيرفر البعيد للبناء؛ لا تفتح منافذ التلفزيون للإنترنت.
3. افتح التطبيق وأدخل مصدرين مباشرين متوافقين محليًا، ثم نفّذ جلسة قصيرة واحدة كما في البرومبت. لا حاجة الآن لقائمة قنوات كاملة.
4. بعد نجاح الأساس فقط، نتحقق من موديل الساوندبار ونجرب عينة Dolby واحدة مناسبة. لا نعد TrueHD Atmos أو DTS لهذا الموديل.
